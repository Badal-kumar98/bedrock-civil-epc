## 🌟 Overview

**Civil Engineer** is a comprehensive corporate web application designed for multi-disciplinary EPC (Engineering, Procurement, Construction) conglomerates. It showcases multi-million dollar structural projects, transportation viaducts, tunneling systems, deep foundation geotechnical data, and client consultation portals.

### ✨ Key Features
- **Project Case Studies Showcase**: High-resolution project portfolios spanning bridges, high-rise structural systems, dams, and rapid rail transit corridors.
- **Interactive Engineering Estimation Tools**: Interactive estimators for concrete volumes, structural steel tonnages, and soil bearing capacity indices.
- **Service Breakdown**: Detailed technical scopes across 6 core disciplines (Structural, Bridges, Geotech, Water/Hydraulics, Highways, Environmental).
- **Responsive Architecture**: Fully mobile-responsive layout designed with modern industrial typography and high-contrast accessibility.

---

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7 (`HashRouter`)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/civil-engineer-epc.git

# Navigate into directory
cd civil-engineer-epc

# Install dependencies
npm install

# Run dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
